## Full continuation state: design only

Native gaussian_model.py:62-94 capture/restore saves Gaussian parameters, active SH, densification accumulators, optimizer state and spatial_lr_scale. It does not save RNG, camera sampling stacks, mip state or loop state. train_with_charts.py:1132 onward restores that tuple, then resets stacks/EMAs and recomputes mip filtering. No original StMary PTH checkpoint was found. Native capture is not an exact continuation.

Required state at a safe boundary:
1. Six Gaussian parameter tensors: xyz, features_dc, features_rest, scaling, rotation, opacity, preserving dtype, device, shape and row order. Active and maximum SH degree.
2. Adam named parameter groups and exact bindings, step counters, first/second moments, group LRs and hyperparameters.
3. max_radii2D, xyz_gradient_accum, denom, percent_dense and spatial_lr_scale.
4. use_mip_filter and the actual mip_filter tensor. Recomputing it on resume is not exact because normal refresh is scheduled at densification or periodic iterations.
5. Full Python random state, NumPy random state, Torch CPU RNG and all visible CUDA RNG states. Synchronize before capture and restore RNG LAST after reconstruction.
6. viewpoint_idx_stack and dense_viewpoint_idx_stack, preserving order and None versus empty list; chart_sampling_phase and current use_chart_view_every_n_iter. The cadence is mutable in dense regularization branches, and next camera selection occurs before its next mutation.
7. Ordered active and late chart pools, selection thresholds, all frozen schedule parameters and current LR state. Rebuild deterministic scheduler functions from original 30,000-step configuration; bind non_position_base_lrs and decay settings. Check next-step LRs.
8. All seven log EMAs: loss, distortion, normal, prior depth, prior normal, prior curvature, prior anisotropy. Completed iteration, next iteration, boundary phase, already emitted save/evaluation events, pipeline/debug configuration.
9. Static inputs: exact ordered cameras, K/R/t, RGB/resolution, masks, backgrounds, charts_data scale, computed chart prior depths/depths/confidences/normals/curvatures/weights and dense depth priors. Save computed caches or reconstruct with equality checks. Restoration must not silently change their content.
10. Runtime binding: source hashes, full parsed arguments, input hashes, package/CUDA/GPU identity and numeric backend/thread flags. Preserve existing flags instead of enabling a new deterministic mode mid-experiment.

Original recipe has color correction, appearance embedding and transient options disabled. Their auxiliary models/optimizers are absent; no exposure optimizer or AMP scaler is in this recipe. A continuation implementation should assert these modes off and fail unsupported modes instead of pretending to capture unimplemented state.

Safe boundary: train_with_charts.py after lines 1943-1954 optimizer.step and zero_grad, after densification/pruning, opacity reset and mip refresh, immediately at the native checkpoint position near 1956. Label completed_iteration=k, next_iteration=k+1, phase=after_optimizer_and_zero_grad. Synchronize, write atomically, fsync, verify hash/readback, then stop before entering the next iteration. Do not use early_stop_iteration at line 1914: it breaks before densification and optimizer work. Iteration 30,000 is terminal and skips optimizer.step; do not treat it as an ordinary continuation boundary.

Restore static scene/caches first, restore parameter/optimizer/mip/loop state next, restore RNG last, then enter iteration k+1 with the unchanged LR update, SH increment, camera selection, render/backward and optimizer ordering. Do not perform a random draw between RNG restore and the next native iteration.
