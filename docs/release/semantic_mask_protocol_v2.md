## 建图两版本与成本边界

STDLoc、ULF-Loc：Cambridge 两个建图分支使用相同图像、标定、初始化、步数和配置；
只切换建图语义过滤。无语义分支仍可使用相同的几何有效性掩码。
切换必须覆盖训练、地标选择、描述子融合、检测器等实际使用语义掩码的建图环节，
不能仅在模型训练后删掉 masks.pkl 就称作“无语义建图”。
各分支在统一无查询语义的协议下输出 stage1 与 stage1+2，计时分增量和累计。

AnyGSLoc 下游不添加语义建图模块；其高斯先验的语义开关作为上游两版本记录。
不能把已用语义训练的 MAtCHA 模型重命名为无语义先验。
先验原生不使用语义时标 N/A，不创建重复开关实验。增量成本不包含上游训练，
但从原始图像开始的总成本表须完整列出；两者不混淆。
