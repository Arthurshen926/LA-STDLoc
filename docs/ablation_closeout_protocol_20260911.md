# AnyGSLoc 消融收尾协议

主线固定 Compact + Fast；不训练描述子、不启用离线反馈，不运行新的24场景正式结果。
本协议是在已有探索之后冻结的确认性汇总协议，不声称未经测试集调参。

## 论文参考与组织

- STDLoc Sec.4.2：https://arxiv.org/html/2503.19358v1 。采样策略比较结合
  容量曲线；其稀疏阶段5m/10deg指标针对初始化任务，不取代我们的最终精度指标。
- ULF-Loc Table6：https://arxiv.org/html/2605.04730v1 。组合消融结合
  50cm/5deg和15cm/5deg召回，分别报告初始与最终位姿。我们只有一次求解，只有最终位姿。

## 固定表格

1. 几何与有效观测：完整重建、无V2、无cycle、无射线稳健重加权。
   每项重新建图并选择Compact，属于系统级单因素消融，地图数目变化须报告。
2. 紧凑地图：Full、Core、Core+Matching、Core+Matching+Pose、等容量质量排序。
   Pose收益必须和等容量对照比较，不能只和小地图比较。
3. 描述子：原融合、普通平均、固定单视角；必须固定相同Compact坐标和点集。
   旧Full上的三场景结果只作为历史诊断，不充当此表。
4. 几何来源：固定点身份与描述子，三角化XYZ对比观测深度反投影聚合XYZ。
   明示共同有效点集及因无效深度排除数量；不以隐藏缺失点制造优势。
5. 附录：completion交互、Fast预算、容量曲线和实际部署资源。

## 固定指标与写作规则

主指标median TE/RE；同时报告R50/5、R15/5、R10/5、R5/5、P90 TE/RE、
>=1m失败数、mean/P50/P90延迟、PnP假设数、实际地图MiB、Anchor数量。
机制指标为GT重投影下raw P@2/P@4（不是物理身份真值）、求解器内点比例。
不根据结果更换主要指标，不删失败查询，不按场景挑种子；场景等权与查询加权分开。
用效果—取舍—限制叙述，不将贪心位姿选择表述为无损/全局充分性证明。
