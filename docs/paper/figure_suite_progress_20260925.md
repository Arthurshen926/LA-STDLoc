## 核验和边界

1. 首次脚本运行成功生成 8 × 3 格式输出，已查看八图联系表；修正了观测图图例和成本图待补说明的重叠。
2. 所有查询照片是当前数据集的真实 processed RGB；不使用 A0/A1 旧版定位或反馈结果。
3. 地图在真实查询上的投影使用数据集 GT 相机；没有做遮挡检测，不把这些点称为可见正确匹配。图注公开此限制。
4. 当前定性素材集中于 ShopFacade，是为了先验证一套可复现的数据通路，不代表五场景定性比较已经完成。
5. 数值统计仍沿用已冻结的场景等权口径；宏平均不是 pooled median。
6. 逐图 sources 当前保守包含截至生成时已读取的来源；全局 manifest 保存所有源哈希，具体选样记录位于 F06.selection。
