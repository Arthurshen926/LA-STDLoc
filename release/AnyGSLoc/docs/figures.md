# Figures and table sources

`reproduction/figures/sources/` contains the nine current editable SVG files. Their SHA-256 values and figure numbers are in `reproduction/figures/index.json`. These are the sources synchronized with the current manuscript, including Full/Compact counts and current vanilla-3DGS experiments. Old dated figure variants are not exported as alternative mainline figures.

| Paper figure | Source | Reproduction basis |
|---|---|---|
| 1 | `Fig1_geometry_to_localization.svg` | conceptual coordinate-estimation/localization illustration |
| 2 | `Fig2_overview.svg` | converter and online localization overview |
| 3 | `Fig3_reconstruction.svg` | tracks, depth-guided augmentation, triangulation, descriptor fusion |
| 4 | `Fig4_selection.svg` | quality/coverage/pose-aware selection; actual map counts |
| 5 | `E1_final_localization.svg` | selected query pose/render comparisons; quantitative evidence is all-query T4 |
| 6 | `E2_geometry_source_evidence.svg` | T5 paired St. Mary's Church mapping-observation residuals |
| 7 | `E3_compact_map.svg` | Full/Compact subsets and descriptor visualization |
| 8 | `E4_gaussian_prior.svg` | prior appearance, landmark maps, pose alignment, reference PSNR |
| 9 | `E5_deployment.svg` | T4 complete-pipeline cumulative latency and deployment storage |

The SVGs embed their displayed raster assets, so their composition remains editable without server paths. Method diagrams are authored illustrations, not experimental outputs to be regenerated by a GPU run. Opening/exporting the SVGs reproduces those compositions; fonts can affect text layout, so use Nimbus Sans for matching typography.

The two quantitative plots can also be regenerated directly:

```bash
python -m reproduction.aggregate --check --output runs/figure_metrics
python -m reproduction.figures.plots --metrics runs/figure_metrics/metrics.json --output runs/figures
```

This writes PDF, SVG, and PNG for Figs. 6 and 9. Fig. 9 obtains every point from recomputed localization, formal timing, and actual deployment bytes; native initial/final points retain their different cumulative stages. Fig. 6 uses the included paired residual arrays, with 1,346,981 observations of 116,303 St. Mary's landmarks. Invalid projections remain in the empirical-CDF denominator.

To plot a newly rerun coordinate control, pass `--geometry runs/cambridge/StMarysChurch/pure_gs/filtered/geometry`. This uses its three `mapping_residuals.npy` files rather than the accepted arrays.

The qualitative panels can be recomposed from the supplied, hash-verified display inputs:

```bash
python -m reproduction.figures.qualitative e1 --output runs/fig5
python -m reproduction.figures.qualitative e3 --output runs/fig7
python -m reproduction.figures.qualitative e4 --output runs/fig8
```

These commands require the optional `figure_inputs` asset bundle. Each copies the inputs into a fresh output directory, verifies their hashes, and redraws the layout, labels, points, crops, and diagonal compositions. E1 also checks its native initial/final pose/error records. They preserve the selected cases and shared descriptor-PCA coloring. This is composition from recorded display assets, not another localization run; to regenerate experimental maps and query results first, use the main/selection/prior recipes. Method diagrams can be edited directly as SVG.

`reproduction/paper_tables/` preserves the 22 accepted TeX tables. `reproduction.aggregate` writes recomputed numeric JSON/CSV; `reproduction.verify_tables` checks 761 locally measured numeric cells across all 22 tables at their displayed precision; it does not silently rewrite literature rows, captions, significance claims, or formatting. T1–T3's other methods are reported literature values with their original citations and coverage, not results generated by this repository.
